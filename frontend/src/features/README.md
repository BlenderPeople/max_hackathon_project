# Feature-модули Ромы

Каждая продуктовая зона получает отдельную папку: `orders/`, `services/`,
`profile/`. Внутри держим экран, локальные компоненты и hook'и для UI.

- Берите данные только из `src/api/` через TanStack Query hooks.
- Проверяйте действия по `availableActions` из API, а не по роли на клиенте.
- Общие визуальные компоненты перемещайте в `src/components/` только после
  второго использования.
- Согласуйте с Сергеем любую правку `src/api/contracts.ts`.
